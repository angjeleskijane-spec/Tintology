## Outstanding source
The previously retained Audi A3 (2002) source/model ID was not present in Phase19 or V17.5 and could not be matched with confidence. It has deliberately not been replaced with a different Audi A3 8L asset. Add it when the exact previously used Sketchfab source is recovered.

## Calibration and validation
This is a vehicle-list expansion/staging build, not a completed per-car calibration release. Sketchfab material IDs for the restored/new vehicles have not been inspected in a live viewer in this environment. Each vehicle still requires live glass/body material mapping and testing of tint response (12% lightest, 95% darkest) and Wrap. Do not treat auto-detected material names as confirmed calibration.

## Locked reference
Ford Mustang Improved's existing Sketchfab UID, material mappings, tint calibration, Wrap behavior, and rendering logic were not edited. It remains the locked reference model.
