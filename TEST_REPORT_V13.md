## Не е потврдено во оваа средина

- Целосен `tsc --noEmit` не заврши бидејќи пакетите не беа инсталирани и недостасува `vite/client`.
- Vite production build не е извршен поради недостапни зависности. Обидот за `npm install` истече.
- Sketchfab live viewer не е тестиран во реален browser session. Затоа не тврдам дека 3D материјалите на двата Porsche модели се веќе визуелно потврдени.
- Вистинското одделување на стаклата зависи од тоа дали Sketchfab моделот ги изложува како различни материјали. Ако не, треба рачно да се мапира точната зона во симулаторот.

## Препорачана локална проверка на Windows

1. Распакувај го ZIP-от во нова папка, без да ја препишуваш старата верзија.
2. Стартувај `START.bat` или во PowerShell изврши `npm.cmd install --legacy-peer-deps`, па `npm.cmd run dev`.
3. Отвори `http://localhost:3000`.
4. На Porsche 911 (930) Turbo тестирај: предни две стакла 12%, заден дел 95%, предно ветробранско 50%; потоа менувај една зона и провери дека другите две остануваат исти.
5. Повтори го тестот на Porsche Cayenne Turbo GT.
6. Провери одделно Light Tint и Car Wrap на двата модели.

Овој извештај ги раздвојува изворните проверки од тестовите што бараат вистински Sketchfab/browser runtime.
